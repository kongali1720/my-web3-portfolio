## 💻 Overview

KONGALI Web3 Portfolio adalah **terminal-style Web3 interface** yang memungkinkan user untuk:

* 🔗 Connect wallet via MetaMask
* 💰 Melihat saldo ETH secara real-time
* 🖥️ UI hacker-style (terminal cyber)
* ⚡ Animasi loading Web3

---

## ⚙️ Tech Stack

* HTML5
* CSS3 (Cyber Terminal UI)
* JavaScript
* Ethers.js
* MetaMask Integration

---

## 🔥 Features

✔ Connect Wallet (MetaMask)
✔ Display Wallet Address
✔ Real-time ETH Balance
✔ Terminal UI Animation
✔ Lightweight & Fast

## ⚡ Installation & Usage

Clone repository:

```
git clone https://github.com/kongali1720/my-web3-portfolio.git
```

Masuk folder:

```
cd my-web3-portfolio
```

Jalankan:

```
Buka index.html di browser
```

---

## 🔐 Requirements

* Browser modern (Chrome / Edge / Brave)
* MetaMask extension terinstall

---

## 🧠 How It Works

Project ini menggunakan **ethers.js** untuk:

* Connect ke Ethereum provider (MetaMask)
* Request wallet access
* Fetch balance dari blockchain
